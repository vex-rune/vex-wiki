# 角色与权限

## 1. 角色概念
PostgreSQL 用 role 统一用户与组概念。

```sql
CREATE USER app_user WITH PASSWORD 'secret' VALID UNTIL '2026-12-31';
ALTER USER app_user CREATEDB;
```

## 2. 权限粒度
- 实例级：CONNECT、SUPERUSER、CREATEDB
- 数据库级：CONNECT、CREATE、TEMPORARY
- 表级：SELECT/INSERT/UPDATE/DELETE/TRUNCATE/REFERENCES/TRIGGER
- 列级：仅 SELECT/INSERT/UPDATE

```sql
GRANT SELECT ON TABLE orders TO app_user;
GRANT SELECT (name, price) ON products TO readonly_role;
```

## 3. 默认权限
```sql
ALTER DEFAULT PRIVILEGES IN SCHEMA public
  GRANT SELECT ON TABLES TO readonly_role;
```

## 4. pg_hba.conf
控制主机认证方式（trust/password/md5/scram-sha-256/peer/ident/cert）。

```
# TYPE  DATABASE        USER            ADDRESS                 METHOD
host    all             all             127.0.0.1/32            scram-sha-256
host    mydb            app_user        10.0.0.0/8              scram-sha-256
```

## 5. 行级安全 RLS
```sql
ALTER TABLE orders ENABLE ROW LEVEL SECURITY;
CREATE POLICY user_orders ON orders
  USING (user_id = current_user_id());
```
