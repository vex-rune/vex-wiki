# 事务与并发控制

## 1. MVCC 原理
- 每个事务看到一致性快照
- 元组上的 xmin/xmax 决定可见性
- UPDATE 产生新版本而非覆盖

## 2. 隔离级别
- READ UNCOMMITTED（实际等同 RC）
- READ COMMITTED（默认）
- REPEATABLE READ
- SERIALIZABLE（SSI）

## 3. 显式事务
```sql
BEGIN;
SAVEPOINT sp1;
UPDATE accounts SET balance = balance - 100 WHERE id = 1;
-- ...
ROLLBACK TO sp1;
COMMIT;
```

## 4. 锁
- 行锁：FOR UPDATE / FOR NO KEY UPDATE / FOR SHARE
- 表锁：LOCK TABLE ... IN ACCESS EXCLUSIVE MODE
- 死锁检测：自动回滚代价最小事务

## 5. advisory lock
应用层命名的锁，不绑定表。
```sql
SELECT pg_advisory_lock(12345);
-- do work
SELECT pg_advisory_unlock(12345);
```
