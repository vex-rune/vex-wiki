# 时序场景对比

## 1. 时序 vs 通用库
| 维度 | TimescaleDB | InfluxDB | 通用 PG |
|------|-------------|----------|---------|
| SQL | 完整 | 类 SQL | 完整 |
| 写入 | 高 | 极高 | 中 |
| 压缩 | 原生 | 原生 | 无 |
| 生态 | PG 扩展 | 自有 | 全 PG |

## 2. Prometheus + TimescaleDB
```yaml
# prometheus.yml
remote_write:
  - url: 'http://cortex:9009/api/v1/push'
remote_read:
  - url: 'http://cortex:9009/api/v1/read'
```

或使用 [prometheus-postgresql-adapter](https://github.com/timescale/promscale) 把 PromQL 翻译为 PG SQL。

## 3. 与向量库组合
```sql
SELECT ts, sensor_id, embedding <=> $1
FROM sensor_vectors
WHERE ts > now() - INTERVAL '1 day'
ORDER BY embedding <=> $1 LIMIT 5;
```
结合时间窗检索最近 K 个相似样本，用于异常检测。

## 4. 选型建议
- 强 SQL / 关联查询 / 业务混合：TimescaleDB
- 极高吞吐/纯监控：InfluxDB / Prometheus
- 极小规模 / 已用 PG：直接用 PG + BRIN 索引
