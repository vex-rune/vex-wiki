# 向量检索实战

## 1. RAG 最小链路
1. 文档切片 → embedding
2. 写入 docs 表
3. 用户问题 → embedding
4. 检索 Top-K
5. 拼到 prompt 调 LLM

## 2. 与 LangChain 集成
```python
from langchain.vectorstores.pgvector import PGVector
store = PGVector.from_documents(
    docs, embedding=embeddings,
    connection_string='postgresql://user:pwd@host/wiki'
)
store.similarity_search(question, k=4)
```

## 3. 多模态扩展
- CLIP embedding 同时存文本/图片向量
- 不同模态检索后用 Re-rank 融合

## 4. 混合检索
```sql
SELECT id, ts_rank_cd(to_tsvector('simple', content), query) AS r,
       1 - (embedding <=> $2) AS s
FROM docs, plainto_tsquery($1) query
ORDER BY (r + s) DESC LIMIT 5;
```

## 5. 运维注意
- 大批量入库：临时关闭索引 → COPY → VACUUM ANALYZE → 建索引
- 定期 vacuum 防止膨胀
- 监控 HNSW 召回率，与全表扫描结果对比
