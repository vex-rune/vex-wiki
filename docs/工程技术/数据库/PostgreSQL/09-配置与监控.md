# 配置与监控

## 1. postgresql.conf 关键参数
| 参数 | 含义 |
|------|------|
| shared_buffers | 共享缓存（建议内存 25%） |
| work_mem | 每操作排序/哈希内存 |
| effective_cache_size | OS 缓存估算（建议内存 70%） |
| maintenance_work_mem | VACUUM/INDEX 内存 |
| max_connections | 最大连接 |
| wal_level | replica/logical |
| max_wal_size | WAL 上限 |
| autovacuum | 自动 vacuum |

## 2. pg_stat 系列
- pg_stat_activity：当前会话
- pg_stat_user_tables：表级统计
- pg_stat_user_indexes：索引使用
- pg_stat_statements：SQL 汇总

```sql
SELECT query, calls, mean_exec_time
FROM pg_stat_statements
ORDER BY mean_exec_time DESC LIMIT 10;
```

## 3. 慢查询
```sql
ALTER SYSTEM SET log_min_duration_statement = 1000;
SELECT pg_reload_conf();
```

## 4. pgBadger
解析 pg_log 生成 HTML 报告。

## 5. 锁等待
```sql
SELECT pg_blocking_pids(pid), *
FROM pg_stat_activity
WHERE wait_event_type = 'Lock';
```
