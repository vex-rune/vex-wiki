# 查询调优

## 1. 统计信息
```sql
ANALYZE orders;
ALTER TABLE orders ALTER COLUMN user_id SET STATISTICS 1000;
```

## 2. prepared statement
```sql
PREPARE q1 (int) AS SELECT * FROM orders WHERE user_id = $1;
EXECUTE q1(123);
DEALLOCATE q1;
```

## 3. 并行查询
```sql
SET max_parallel_workers_per_gather = 4;
SET parallel_tuple_cost = 0.01;
```

## 4. 常见陷阱
- 隐式类型转换使索引失效
- 对索引列使用函数（除非函数索引）
- LIKE '%xx%' 无法走 B-Tree（用 pg_trgm + GIN）
- 大量 OFFSET 分页性能差，改用 keyset 分页

## 5. keyset 分页
```sql
SELECT * FROM orders
WHERE (created_at, id) < ($1, $2)
ORDER BY created_at DESC, id DESC
LIMIT 20;
```
