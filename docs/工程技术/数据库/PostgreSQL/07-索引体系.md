# 索引体系

## 1. 索引类型
| 类型 | 适用 |
|------|------|
| B-Tree | 范围/等值（默认） |
| Hash | 仅等值 |
| GIN | jsonb、数组、全文、trgm |
| GIST | 几何、范围、IP |
| BRIN | 大表时序/自然有序 |
| SP-GiST | IP、电话前缀、trie |

## 2. 创建示例
```sql
CREATE INDEX idx_orders_user ON orders(user_id);
CREATE INDEX idx_orders_expr ON orders((total / qty));
CREATE UNIQUE INDEX idx_users_email ON users(email);
CREATE INDEX idx_orders_partial ON orders(created_at)
  WHERE status = 'paid';
```

## 3. jsonb 索引
```sql
CREATE INDEX idx_users_profile_gin ON users USING gin(profile);
CREATE INDEX idx_users_name ON users((profile->>'name'));
```

## 4. 复合索引顺序
- 遵循最左前缀
- 高选择性列放前面
- 范围列放最后
